🚀 VibeVoice


AI-Powered Voice Generation & Processing App
VibeVoice is a modern AI-based voice application that enables users to generate, process, and interact with speech using advanced Text-to-Speech (TTS) technology.

📌 Features:


🎤 Text-to-Speech (TTS) – Convert text into natural human-like voice
🧠 AI Voice Processing – Smart handling of speech inputs
🔊 Multi-Voice Support – Different voice styles and tones
⚡ Real-time Generation – Fast and efficient output
🌐 Web Interface – Clean and user-friendly UI
💾 Download Audio – Save generated speech files

🧠 About VibeVoice:


VibeVoice is designed to simplify voice generation using AI. It allows users to convert text into speech seamlessly while providing a smooth and interactive experience.

🛠️ Tech Stack:


Backend: Python (Flask / FastAPI)
Frontend: HTML, CSS, JavaScript
AI Models: Text-to-Speech (TTS)
Libraries: PyTorch, Transformers, Speech Libraries


⚙️ Installation:


1. Clone the Repository
git clonehttps://github.com/Nikhildusa07/VibeVoice.git
cd VibeVoice

2. Create Virtual Environment
python -m venv venv
venv\Scripts\activate (Windows)

3. Install Dependencies
pip install -r requirements.txt

4. Run the App
python app.py

5. Open in Browser
http://localhost:5000
